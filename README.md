# Mamon Coffee Roaster Website

เว็บไซต์ต้นแบบสำหรับโรงคั่วกาแฟมาม่อน บริษัท นานาดอย จำกัด ออกแบบเป็นเว็บไซต์แบบหน้าเดียว รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## ดูเว็บไซต์ในเครื่อง

เปิดไฟล์ `dist/index.html` ด้วยเว็บเบราว์เซอร์ หรือให้บริการโฟลเดอร์ `dist` ผ่าน local web server

## เผยแพร่

โฟลเดอร์ `dist` พร้อมนำไปเผยแพร่ผ่าน GitHub Pages, Vercel, Netlify หรือ static hosting อื่น ๆ ได้ทันที

## โครงสร้างหลัก

- `dist/index.html` — เนื้อหาและโครงสร้างเว็บไซต์
- `dist/assets/styles.css` — รูปแบบและ responsive design
- `dist/assets/script.js` — เมนูมือถือและเอฟเฟกต์ขณะเลื่อนหน้า
- `dist/assets/images/` — ภาพจริงของกิจการ
